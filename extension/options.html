Settings · version 1

The search box can't open on this settings page. Chrome doesn't let extensions run on its own pages: settings pages, chrome:// pages, the New Tab page, or the Web Store. Open a normal website and press the shortcut there.

Jev API key optional

Jev finds the answer on the page, fast. Without a Jev key, Nemotron finds it instead. Get a key at console.typesafe.ai/keys: sign in, click + Create key, name it, click Create key, and copy it (it starts with apikey_). It's saved only in this browser, on this computer.

Nebius key, for NVIDIA Nemotron optional

Nemotron is NVIDIA's family of open models, run by Nebius Token Factory. Pareto uses three of them:

  • Nemotron 3 Super writes the short answer after each search.
  • Nemotron 3 Ultra thinks harder when you press ⌘ Enter: it reads the whole page and answers questions that need all of it.
  • Nemotron 3.5 Lightning finds the answer when there's no Jev key, when Jev can't, or when a page is too long for Jev. It also races Jev in compare mode.

Get a key at tokenfactory.nebius.com and paste it here. It's saved only in this browser, on this computer, and is sent only to Nebius.

Privacy: Nebius keeps what it's sent unless Zero Data Retention is on for your account. Switch it on in your account profile at tokenfactory.nebius.com.

Endpoint and models

Leave these alone to use the defaults. Change a model id only if Nebius renames one: Check the key shows whether each is listed.

AI answers optional

After each search, an AI writes a short answer from the best-matching part of the page. It's sent the question and those excerpts only.

Endpoint and model

Any OpenAI-compatible chat API works: OpenAI, OpenRouter, Groq, or a server of your own. Leave these alone to use the defaults. A different endpoint asks Chrome for permission to reach it when you save.

How to use

Open the box on any normal website: the Control key, not ⌘ Command. Or click the toolbar icon.
Type
Words light up on the page as you type, like normal Ctrl+F
Enter
With a Jev or Nebius key: search by meaning. Without one: next word match.
⌘ Enter
Think harder: Nemotron 3 Ultra reads the whole page, answers, and highlights the parts it used
↑ ↓
Step through the matches
Shift ↑ ↓
Step through word-for-word matches
Option Enter
Compare mode: Jev against Nemotron Lightning (or your AI), side by side
Esc
Close the box and clear the highlights
